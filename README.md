# WindowShine — Charlotte Exterior Residential Window Cleaning

> Crystal-clear windows. Pure Carolina light.

WindowShine is a modern, high-performance website for an exterior residential window cleaning service serving Charlotte, NC and surrounding communities (Myers Park, Ballantyne, Dilworth, SouthPark, Lake Norman, Matthews, Waxhaw, and more).

Designed and crafted using **IMPECCABLE** design standards:
- **100% Exterior Focused**: No interior intrusion, no need for the homeowner to be home.
- **Interactive Squeegee Reveal**: Tactile interactive before/after squeegee comparison slider demonstrating the clarity professional exterior cleaning brings.
- **Straightforward Estimate & Booking**: Select home type and window count range to submit a quick estimate request.
- **Charlotte Local**: Coverage badges across Greater Mecklenburg County.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Figtree & Plus Jakarta Sans
- **Deployment**: [Vercel](https://vercel.com/) (zero-config, instant edge deployments)

---

## 🚀 Local Development

To run WindowShine locally:

```bash
# Install dependencies
npm install

# Start local Vite development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
